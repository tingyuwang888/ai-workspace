二、TdAlly 多Agent协作探索 方案验证中
TdAlly（v0.0.1b7）是公司自研的本地化 AI Agent 桌面平台，基于 Tauri 构建。探索用其 Loop Team 编排多个 Agent 协作完成天策策略配置全流程。
1
智能体配置 — Leader-Worker 角色分工
配置了 6 个智能体组成策略配置流水线：Leader（天策配置编排助手）不挂 Skill 只负责调度；Worker 各挂一个 Skill（数据助手负责元数据、函数配置助手生成 .fun、规则配置助手生成 .rss）。通过共享工作区 ~/tiance_workspace/ 按文件交接数据。
2
Loop 任务发起 — 自动确认目标与边界
用户发送 /loop 指令后，Leader 自动解析任务目标，确认 Excel 路径、执行流程（拉取元数据 → 生成 .fun）、目标平台地址、成功标准和停止边界，然后开始调度 Worker 执行。
3
执行报告 — 多 Agent 协作成果汇总
三峡项目函数配置任务完成，3 步流程全部通过：元数据确认（数据助手判断无需重新拉取）→ 函数生成（函数配置助手输出 .fun 文件并验证通过）→ 汇总。产出 3,880B 的平台导入文件和 11,735B 的 JSON 参考。
