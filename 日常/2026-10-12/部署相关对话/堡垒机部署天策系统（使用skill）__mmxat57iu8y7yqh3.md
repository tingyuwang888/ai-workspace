deepseak r1模型是不是不支持使用skill？

### 🤖 助手 · 2026-03-23T01:54:32.798Z

这个问题涉及到 QoderWork 中不同模型对工具调用（tool use）能力的支持情况。Skill 的执行依赖模型的 function calling 能力——模型需要能识别何时调用工具、正确传参、并处理返回结果。

DeepSeek R1 是一个侧重推理（reasoning）的模型，在工具调用方面的支持确实可能不如其他模型完善，这会导致 skill 无法正常触发或执行异常。如果你发现切换到 R1 后 skill 不工作，这很可能就是原因。

建议在需要使用 skill 的场景下选择对 tool use 支持更好的模型。具体哪些模型支持哪些能力，可以到 https://docs.qoder.com/qoderwork/introduction 查看最新的模型能力说明，或者在 https://forum.qoder.com/ 上搜索相关讨论。

### 🧑 用户 · 2026-03-23T01:55:44.410Z

那我怎么使用DeepSeek R1 模型去部署天策环境呢？

### 🤖 助手 · 2026-03-23T01:55:44.421Z

其实 skill 本质上就是一组 markdown 文档，即使模型不支持自动调用 Skill 工具，你也可以手动让 R1 读取这些文件来获取部署知识。

最简单的做法是在对话开头让 R1 直接读取 skill 文件：

```
请先阅读以下文件，然后按照里面的步骤帮我部署天策环境：

~/.qoderwork/skills/jumpserver-tiance-deploy/SKILL.md
~/.qoderwork/skills/jumpserver-tiance-deploy/deploy-steps.md
~/.qoderwork/skills/jumpserver-tiance-deploy/troubleshooting.md
~/.qoderwork/skills/jumpserver-tiance-deploy/nginx-config.md
```

只要 R1 支持文件读取（Read 工具）和命令执行（Bash 工具），它就能按文档里的步骤逐步操作。Skill 工具只是一个"自动加载说明书"的快捷方式，手动把说明书喂给模型效果是一样的。

如果连基础工具调用都不稳定，那还有个更轻量的方案：把 skill 当作你自己的参考手册，你来告诉模型每一步该执行什么命令，模型只负责跑命令和看结果。
