# X3 决策树手工搭建 · 照着点清单

环境：天策 Noah POC（orgCode=sxdb 三峡担保）· 决策中心 → 决策工具 → 编辑区
目标：建一棵最小可测决策树并上线，之后自动化接手（读 schema + 建引用策略 + 跑用例 + 报告）。

设计（用已确认存在的两个 double 系统字段）：
- 切分字段：个人月收入909（C_F_SALARY909）
- 输出字段：个人月收入908（C_F_SALARY908）
- 规则：909 ≤100 → 908=1；909 >100 → 908=2；默认(else) → 908=0

---

## 第 1 步：新建决策树

1. 左侧菜单进入「决策工具」，切到顶部「编辑区」标签。
2. 点右上「新增」。
3. 弹窗「新增决策工具」里点最左边那张卡「决策树」。
   → 跳到「添加决策树」页，默认在「基础信息」标签。
   → 「标识」会自动生成一个 `TREE…` 开头的编码（记下它，稍后核对）。

## 第 2 步：填基础信息

4. 所属渠道：下拉选「初始应用」。
5. 名称：填 `决策树测试gf3`。
6. 描述：可留空。
7. 默认决策（必填）：
   - 决策方式：选「字段赋值」。
   - 目标字段（级联选择器，逐级点）：点一下展开 →「字段」→「系统字段」→「个人月收入908」。
   - 中间运算符保持「=」。
   - 值类型保持「常量」。
   - 值输入框：填 `0`（会自动变成 0.00，正常）。

## 第 3 步：进「决策树设计」画布

8. 点顶部「决策树设计」标签。画布会预置一棵起步树：根「节点」→「配置条件」→「决策」叶子。右上角会显示「3 项不完善」，逐项配好即可清零。

9. 配置根节点（切分字段）：
   - 点根「节点」卡片右侧的「配置节点 ›」（若只选中不弹面板，双击卡片或点 › 箭头）。
   - 切分字段选：字段 → 系统字段 →「个人月收入909」。
   - 确认/保存该节点配置。

10. 配置第一条分支条件：
    - 点「配置条件」，加一条：`个人月收入909 ≤ 100`（比较符选 ≤，值填 100）。
    - 这条分支下方的「决策」叶子 →「配置决策」：字段赋值 个人月收入908 = 常量 `1`。

11. 加第二条分支：
    - 点分支之间的「+」新增一条分支。
    - 条件：`个人月收入909 > 100`。
    - 该分支「决策」叶子 →「配置决策」：字段赋值 个人月收入908 = 常量 `2`。

12. 确认右上角「N 项不完善」消失（应变为 0 或不再红）。若仍有提示，点它定位到未配的节点补齐。

## 第 4 步：保存 + 上线

13. 点右上「保存」。等列表/提示成功。
14. 点右上「上线」→ 弹出发布抽屉：
    - 发布类型：普通（默认）。
    - 发布版本：下拉选 `V1`。
    - 发布说明：可留空。
    - 点「确定」。
    → 提示「执行成功」即上线完成。

## 完成后告诉我

回一句「决策树已上线」即可。我会自动接手：
- 用接口读回并固化 D_TREE 的 content 字节 schema（免导出）；
- 建一条引用该决策树的流模式策略、连线、保存、上线；
- 跑分支用例（909=50→期望908=1；909=200→期望908=2；909空→期望默认）并交叉核对；
- 出 X3 五态报告并归档、更新清理交接。

## 备注 / 避坑

- 若「配置节点」抽屉点不开，多半是点到了卡片空白处（只选中）；请点右侧「›」箭头或双击卡片文字区。
- 级联字段选择器要点三级才回填：字段 → 分类（系统字段）→ 具体字段名。
- 常量值框会自动补两位小数（0→0.00、1→1.00），不影响。
- 名称/字段名以你界面实际显示为准；如「个人月收入908/909」不在系统字段里，换任意两个可用的 double 数值字段即可，保持"切分用A、输出用B"两列不同就行，并把实际字段名告诉我。
