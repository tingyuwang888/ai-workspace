### 目的

上一批（DT策略引用批）验证了策略引用「决策表（一维单条件）」的链路。本批把复杂度提升到**决策矩阵（D_MATRIX）**——含 X/Y 双轴、每轴多分桶、以及第二 X 轴作为「门禁」的多维命中模型。目标是端到端验证：策略请求参数 → 决策工具入参映射 → 矩阵按（评级行 × 收入列）二维命中并受 908 门禁约束 → 出参回写 → 策略决策结果，覆盖每个单元格、每个分桶边界值、行切换与门禁兜底。

### 决策矩阵逻辑（来自导出 JSON 反推）

Y 轴 `C_S_YWDLFXQ`（业务代理人反洗钱评级，string）：=通过→第 0 行，=拒绝→第 1 行。
X 轴主字段 `C_F_SALARY909`（个人月收入909，double）三桶：≥10000→第 0 列，<100→第 1 列，≥100 且 <10000→第 2 列。
X 轴第二字段 `C_F_SALARY908`（个人月收入908，double）为门禁：要求「不为空」，否则整行不命中。
矩阵取值 `data=[[10000,100,1000],[20000,100,2000]]`（[行][列]）。
出参 `C_F_SALARY919`（个人月收入919，double）= 命中单元格值；默认决策（else）= 0。
即：919 = data[评级行][909分桶]，前提 908 不为空，否则回落默认 0。
